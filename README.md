# 房租提醒 - 安装指南

## 应用简介

房租提醒是一款帮助房东管理租金账单的移动应用，支持：
- 管理多个房客信息
- 自定义起租日期和交租周期
- 记录交租状态，支持自定义确认
- 逾期提醒功能
- 数据本地存储，保护隐私

## 如何安装到 Android 手机

### 方法一：使用 PWABuilder 在线转换（推荐）

1. **部署应用到网上**
   - 将整个 `rent-reminder` 文件夹上传到任何网页托管服务
   - 推荐使用免费的 GitHub Pages 或 Vercel

2. **访问 PWABuilder 转换**
   - 打开浏览器访问：https://www.pwabuilder.com/
   - 在输入框中输入您的应用网址
   - 点击 "Start" 按钮

3. **生成 Android APK**
   - 选择 "Android" 平台
   - 点击 "Generate Package"
   - 下载生成的 APK 文件

4. **安装到手机**
   - 将 APK 文件发送到手机
   - 在手机上打开 APK 文件
   - 如果提示"禁止安装未知来源应用"，请前往设置 > 安全 > 允许安装未知来源应用
   - 完成安装

### 方法二：直接在手机浏览器安装 PWA

1. **打开应用**
   - 用手机浏览器（推荐 Chrome）打开应用网址

2. **添加到主屏幕**
   - 点击浏览器菜单按钮（三个点）
   - 选择"添加到主屏幕"或"安装应用"
   - 按照提示完成安装

## 功能说明

### 首页
- 查看所有待交租的房客列表
- 按逾期程度排序显示
- 点击房客卡片查看详情

### 房客管理
- 添加新房客（姓名、电话、租金、起租日期、交租日期、交租周期）
- 编辑房客信息
- 删除房客
- 点击"确认交租"记录交租信息

### 交租记录
- 查看所有历史交租记录
- 包含交租月份、确认日期、确认人、备注
- 可删除错误记录

### 设置
- 调整提前提醒天数
- 设置提醒时间
- 导出/导入数据备份
- 清除所有数据

## 常见问题

### Q: 安装后无法打开？
- 确保手机系统为 Android 7.0 或更高版本
- 尝试重新安装

### Q: 数据会丢失吗？
- 应用数据保存在手机本地
- 建议定期使用"导出数据"功能备份

### Q: 如何转移数据到新手机？
- 在旧手机上导出数据
- 在新手机上导入数据
